Install Lexora

Lexora is available on the Chrome Web Store. Install in seconds — no Developer Mode or manual steps required.

Chrome Web Store — recommended

Install from the Chrome Web Store.

Lexora v0.18.0 is approved and available on the Chrome Web Store. Install directly from the store — no sideloading or Developer Mode required.

Open Chrome Web Store
  1. Open the Chrome Web Store listing for Lexora.
  2. Click "Add to Chrome" and confirm the permissions prompt.
  3. Pin the Lexora icon to the Chrome toolbar for quick access.
  4. Select text on any web page to open the Lexora reading panel.
Developer Mode — contributors only

For contributors and local development.

Developer Mode installation is intended for contributors and local development only. Normal users should install from the Chrome Web Store above.

Current extension version v0.18.0

Developer Mode install — contributors only

These steps are for contributors building and testing Lexora locally. Normal users should use the Chrome Web Store.

  1. Obtain the extension package from the project maintainer.
  2. Extract the package to a local folder.
  3. Open chrome://extensions in Chrome and enable Developer Mode (top-right toggle).
  4. Click Load unpacked and select the dist/ folder from the extracted package.
  5. Open the extension options page to configure languages, providers, and privacy settings.
