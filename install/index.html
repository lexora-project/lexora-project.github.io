Developer Mode — current fallback

Manual install for contributors and testers.

Until the Chrome Web Store testing link is available, Lexora can be installed manually via Chrome's Developer Mode. This path is intended for contributors and early testers.

Repository https://github.com/lexora-project/lexora
Current extension version v0.18.0

Developer Mode install steps

  1. Download the latest release archive from the extension repository.
  2. Extract the downloaded archive to a local folder.
  3. Open chrome://extensions in Chrome and enable Developer Mode (top-right toggle).
  4. Click Load unpacked and select the dist/ folder from the extracted archive.
  5. Open the extension options page to configure languages, providers, and privacy settings.
