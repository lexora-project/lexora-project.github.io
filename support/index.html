Contact

Reach the Lexora team at: lexora.dev@proton.me

Support paths

  • General usage — install questions, language settings, provider setup
  • Bug reports — reproducible issues with extension behavior
  • Security reports — report sensitive issues privately. See the security page.
  • Feature feedback — suggestions related to reading flow, language workflow, or interface behavior

For bug reports, include:

  • browser name and version
  • Lexora version (visible in the extension options page)
  • operating system
  • language pair (source and target language)
  • provider mode (which translation or AI provider is active)
  • reproduction steps
