Changelog

Public release notes for the Lexora extension.

Version 0.19.3

2026-10-16

Available on Chrome Web Store

Reliability and consistency

Lexora v0.19.3 is published and publicly available on the Chrome Web Store. Public availability was confirmed on October 16, 2026.

  • More reliable Notebook saves, duplicate detection across websites, and bookmark synchronization between tabs.
  • Fixed incorrect cached translations for long selections that share the same beginning.
  • More reliable settings persistence across contexts, with clear errors when a save fails.
  • Improved YouTube DualSubs loading and language changes. Temporary rate limits can still require a short wait before retrying.
  • Restored reliable Wikipedia references when enabled.
  • Improved selection handling in embedded frames after the background worker restarts.
  • Completed Notebook labels, filters, notices, and controls across all ten interface languages.
  • Removed verified obsolete extension code and unused website content.

Version 0.19.2

2026-10-15

Historical release

Stability and recovery

Lexora v0.19.2 is published and publicly available on the Chrome Web Store. Public availability was confirmed on October 15, 2026.

  • Keep Cloud AI provider selection and saved credentials consistent.
  • Recover stalled translation loading with bounded requests and retries that preserve the current selection.
  • Restore reading panel and selection handling after browser back/forward navigation, including BFCache restores.
  • Clear stale YouTube DualSubs text when subtitle timing, video, or language changes invalidate a cue.
  • DualSubs controls follow the selected interface language across 10 existing locales; no translation target languages are added.

Version 0.19.1

2026-10-10

Historical release

Popup and update awareness

Lexora v0.19.1 is published and publicly available on the Chrome Web Store. Public availability was confirmed on October 10, 2026.

  • Improved the browser toolbar popup UI with clear feature status, settings access, and compact secondary links.
  • The popup dynamically displays the installed extension version from the manifest.
  • Genuine extension upgrades show an update announcement and a NEW toolbar badge until acknowledged. First installation, startup, popup reopening, and same-version reload do not create a new announcement.
  • Bundled What’s New release notes work offline. Opening the notice’s What’s New link or dismissing the notice acknowledges the installed version.
  • Improved YouTube DualSubs popup controls and contextual player-control guidance, with keyboard navigation, focus indicators, and accessible switches.

Version 0.19.0

2026-10-08

Historical release

Browser-native Translation

Lexora v0.19.0 is published and publicly available on the Chrome Web Store. Public availability was confirmed on October 9, 2026.

  • Added On-device Translation using Chrome’s built-in Translator API, with in-panel language-pack preparation, progress, cancellation, and retry guidance.
  • Choose On-device Translation, online Google Translate, or Cloud AI with user-supplied Gemini, OpenAI, or Anthropic keys. Supported prepared pairs can translate offline on-device; failures never silently select a remote provider.
  • Improved Cloud AI connection handling and translation-mode persistence. Removed Ollama and custom endpoint support; legacy endpoint selections migrate to On-device Translation.
  • Reading Panel, Japanese reading and pronunciation, Wikipedia/Wikidata, Notebook, and YouTube DualSubs remain available with their own settings and network behavior.

Version 0.18.4

2026-09-06

Historical release

More reliable reading and translation

Lexora v0.18.4 improves reading-panel reliability and translation timeout handling. It is available publicly on the Chrome Web Store.

  • Apply Google translation timeouts while the response is being read and processed.
