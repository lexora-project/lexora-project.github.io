Help

The goal of this page is to explain the product quickly and reduce onboarding friction. Keep it practical.

What Lexora does

Select text on a page and Lexora opens a dedicated side panel with translation, explanation, and supporting context.

Reading workflow the site should teach

  1. Select text.
  2. Review translation and explanation together.
  3. Use pronunciation where needed.
  4. Check entity context when the Wikipedia lane appears.
  5. Adjust provider or privacy settings only when necessary.

Avoid teaching the wrong behavior

The help surface should not train users to treat Lexora as a generic AI chatbot. The product is strongest when it stays anchored to reading context and controlled augmentation.
